# Contributing to Awesome Agentic Memory

Thank you for helping make this the definitive resource for agentic memory!

## How to Add an Entry

1. **Fork** this repository
2. **Edit** `README.md`
3. **Add** your entry under the most appropriate section
4. **Submit** a Pull Request

## Entry Format

```markdown
### Project Name

[![GitHub Stars](https://img.shields.io/github/stars/OWNER/REPO?style=flat-square)](https://github.com/OWNER/REPO)

> One-line description of what makes it special.

- **GitHub**: https://github.com/owner/repo
- **Key feature**: What sets it apart
```

For simpler entries in tables, use:
```markdown
- [Name](URL) — Brief one-line description
```

## Inclusion Criteria

- **Open-source** OR has substantial free public documentation
- **Actively maintained** — last commit within 12 months (except historically significant projects)
- **Relevant** — must directly address memory for AI agents
- **Documented** — must have a README with setup instructions or examples
- **Working** — no obviously broken or placeholder projects

## What NOT to Submit

- Abandoned projects with no recent activity
- Pure wrappers with no added value
- Projects that are just copies of listed projects
- Self-promotion without clear community benefit
- Broken links

## PR Guidelines

- PR title: `Add [ProjectName] to [Section Name]`
- One project per PR (exceptions for closely related tools)
- Verify all links work before submitting
- Sort alphabetically within sections where applicable
- Do not update star counts — these are kept as approximate snapshots

## Updating Existing Entries

- **Fix broken links**: Always welcome — just submit a PR
- **Fix descriptions**: If factually wrong or outdated
- **Add code examples**: If a section is missing examples
- **Update status**: If a project changes license, gets abandoned, etc.

## Reporting Issues

- Broken links: Open an issue with `[broken link]` in the title
- Wrong category: Open an issue describing where it should go
- Missing project: Open an issue or submit a PR directly

## Code of Conduct

Be respectful. This is a collaborative resource. See the [Contributor Covenant](https://www.contributor-covenant.org/) for guidelines.
